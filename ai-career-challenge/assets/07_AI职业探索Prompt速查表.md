# AI职业探索 Prompt 速查表

复制整段后，把 `[方括号]` 内容换成自己的信息。职业建议仅用于探索，不是正式职业测评，也不代表实习、就业或录用承诺。涉及学校、招聘、活动、待遇的信息请回到官方来源核实。

## Prompt 01｜让AI认识我

```text
你是一名耐心的大学生职业探索教练。请根据以下信息，帮我整理一张“我的信息画像”：专业：[专业]；年级：[年级]；兴趣：[兴趣]；擅长事情：[擅长]；不喜欢事情：[不喜欢]；希望解决的问题：[问题]。请输出：1.我的3个关键词；2.可能的优势；3.我还需要补充确认的3个问题。不要替我下结论，不要把推测写成事实。
```

## Prompt 02｜发现我的职业探索方向

```text
你是一名大学生AI职业探索教练。基于我的个人信息：[粘贴个人信息]，请提供3—5个值得我进一步了解的AI相关职业探索方向。每个方向请写：主要做什么、我可能已有的可迁移能力、还需补的能力、一个大学期间可以完成的小练习、为什么值得我亲自验证。请使用“探索建议”措辞，不要进行正式职业测评，不要说我一定适合或一定能就业。
```

## Prompt 03｜拆解一个职业

```text
请拆解职业探索方向“[岗位或方向名称]”。面向没有行业经验的大学生，用通俗语言输出：1.一天可能做的典型任务；2.服务的对象；3.常见交付物；4.需要的能力；5.适合尝试这个方向的人可能有哪些特点；6.大学期间可做的3个低成本体验项目；7.我应该向从业者核实的5个问题。请说明不同公司会有差异，不要编造具体公司信息。
```

## Prompt 04｜分析一个招聘JD

```text
请帮我读懂下面这条招聘JD：[粘贴JD]。请输出：1.公司真正要解决的业务问题；2.岗位日常任务；3.必须能力与加分能力；4.我已有经历中可能对应的证据：[粘贴经历]；5.能力差距；6.30天补差距计划；7.我应该向招聘方确认的5个问题。只根据JD和我提供的经历分析，不要推断公司承诺，不要保证我能通过面试。
```

## Prompt 05｜生成30天行动计划

```text
我想探索“[方向]”，每周可投入[小时数]小时，已有基础是[基础]，希望做出一个可展示的小作品。请制定30天计划，按第1周至第4周输出：学习目标、实践任务、当周可保存的成果、验收标准、预计耗时和风险。计划要从小到大，优先使用免费或现有工具。最后给出第1天立刻能做的20分钟任务，不要承诺实习或就业结果。
```

## Prompt 06｜发现校园AI场景

```text
你是一名校园流程观察员。请根据我的校园场景：[场景，例如社团招新/课程复习/宿舍协作]，帮助我找出3个可以用AI改善的小问题。每个问题请输出：目标用户、当前做法、浪费的时间或造成的困扰、可尝试的人工方案、AI能辅助的环节、不能交给AI的判断、最小验证方法。请把事实、我的假设和待验证问题分开。
```

## Prompt 07｜把想法变成作品

```text
我想解决的问题是：[问题]，目标用户是：[用户]，我拥有的材料和工具是：[材料/工具]，可用时间是：[时间]。请把想法拆成：问题定义、用户需求、核心功能（最多3个）、输入、输出、操作流程、保底版本、验收标准、展示时的一句话介绍。先做能在今天完成的最小作品，不要增加未被要求的复杂功能。
```

## Prompt 08｜生成我的HTML AI职业探索助手

```text
请生成一个完整、可离线打开的单文件HTML，标题为《我的AI职业探索助手》。要求：所有HTML、CSS、JavaScript都写在同一个文件；不依赖服务器、数据库、外部CDN或网络字体；双击即可打开；适配手机和电脑；使用明亮蓝色、橙红色、少量黄色和白色卡片；包含可编辑的个人标签、优势、3个职业探索方向、方向说明、能力雷达或能力可视化、未来30天计划、AI作品记录；提供保存/打印按钮或清晰的本地保存提示；页面必须显示“这是职业探索小游戏/建议，不是正式职业测评，也不代表实习、就业或录用承诺”。请输出完整代码，不要省略任何部分。
```

## Prompt 09｜优化我的AI作品

```text
这是我的AI作品说明：[粘贴说明或代码片段]，目标用户是：[用户]。请从“是否解决问题、信息是否完整、使用是否容易、表达是否清楚、风险与隐私”五个方面检查，给出最值得优先修改的3处。每处说明：当前问题、修改理由、具体改法、验收方式。不要为了炫技增加复杂功能，不要编造用户反馈。
```

## Prompt 10｜一分钟作品介绍

```text
请把我的作品信息整理成一段60秒口头展示稿。作品名称：[名称]；我发现的问题：[问题]；目标用户：[用户]；我做了什么：[作品]；AI帮我完成了什么：[AI作用]；最终结果：[结果]；如果再做一次我会改进：[改进]。结构必须是：问题—行动—AI作用—结果—下一步。语气自然、适合大学生现场分享，不夸大效果，不承诺就业。
```

## 使用小口诀

先说清目标，再补充材料；指定输出格式，写明限制条件；AI给方案，人来判断；保存过程，才能讲清作品。
